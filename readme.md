
# TS Functions

This is a library of MATLAB general utilities I wrote as macros for common structure operations within my Matlab code. 

This repo was primarily established as a dependency for my other libraries and repos. Thus, these are designed as orphan functions, which have no external dependencies, and can be dropped into the utils file of a larger repo, or as a library called as a standalone dependancy. 

That said, no guarantee is given that these functions are fully documented, will work as expected, or indeed will do anything. I wrote these functions because they are useful for *me*, without any expectation that they will be useful for *you*.

If you use any of my functions, you must maintain my name and attribution within the script function. You must also cite this repo as the source of the function (how you do this, be it within the list of dependancies, or a link out, etc is up to you.) No implication should be made that I endorse or promote derivative products using these functions. 

If you would like to contribute to any of these functions, send a pull request.
